## Project Goal

Jarvis was designed as a desktop AI home hub: a small interactive companion that could talk, react with expressions, control appliances, and run locally for better privacy.

The system combined a higher-level AI layer with a real-time microcontroller layer. Jetson Orin Nano handled voice, vision, and dialogue. The NXP FRDM-MCXN947 side handled GUI state, touch input, facial expressions, servo movement, and command communication.

## My Role

My main work was around AI dialogue architecture, agent behavior, and human-machine interaction flow. The goal was to turn user requests into concrete actions:

- head pitch and yaw movement,
- facial expression changes,
- weather and time information,
- music playback,
- appliance control commands.

This required thinking about command format, communication delay, module responsibility, and exception handling.

## Result

The project won first prize in the MakeNTU 2026 NXP x AVNET smart-life application challenge. More importantly for my portfolio, it shows that I can connect AI behavior with embedded devices and user-facing interaction.
